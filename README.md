
# Ghost In The Shell (Playstation) Source

## What

This is source code for the Playstation One game "Ghost in the Shell".
https://www.mobygames.com/game/4903/ghost-in-the-shell/

This is not the original source code, its entirely new source code that replicates the behavior of the original game exactly.

## Why

For educational purposes. Exploring and learning about console game development and the techniques used.

This won't be useful for playing or modifying the game. To turn this source into an executable, you'd need to create the necessary build scripts, track down a few assets that get installed directly into the game binaries, obtain the original compiler and sdk libs used, and even then you'd still need a copy of the original game for the game files.
